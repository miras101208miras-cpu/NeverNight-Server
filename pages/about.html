// О проекте

Экосистема EcosystemNever

EcosystemNever — это моя личная экосистема сайтов, сервисов и ботов. Я собрал её с нуля: от статичных страниц на GitHub Pages до полноценного Node.js-сервера с чатом в реальном времени, базой данных и Telegram-уведомлениями. Всё в едином неоновом стиле.

🗺 Как развивалась
Шаг 1
Первые сайты
Начал с фан-сайтов и лендингов на GitHub Pages — так появились EcosystemNever и Demon Slayer.
Шаг 2
Свои продукты
Собрал NeverParty для совместного просмотра и Telegram-бота экосистемы.
Шаг 3
Портфолио
Сделал портфолио NeverNight со всеми проектами и демо-сервисами.
Шаг 4
Собственный сервер
Написал Node.js-сервер: чат (Socket.IO), гостевая книга, стена идей, мониторинг и админ-панель с паролем.
Шаг 5
Развитие и аналитика
Добавил каталог проектов, страницу профиля, страницу о проекте и свою аналитику посещений.
Шаг 6
Единый стиль и игра
Сделал общий дизайн для всех страниц, переключатель светлой/тёмной темы, мобильную версию и неоновую мини-игру NeverGame с таблицей рекордов.
Шаг 7
Ассистент и музыка
Добавил Never Assist — ассистента экосистемы, который сам ищет треки и добавляет их в плейлист, и NeverMusic — музыкальный плеер с общим плейлистом и визуализацией.
⚙️ Технологии
Node.js Express Socket.IO SQLite JavaScript HTML5 CSS3 Canvas API Web Audio API Telegram Bot API GitHub Pages Render Git
